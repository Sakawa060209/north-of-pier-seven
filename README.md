# 第七码头以北

一款无需后端、可直接在浏览器运行的案件调查推理游戏。

## 游戏简介

2004 年 12 月，临川市北七码头街区连续出现五名死者。数字、黑色相纸与来自同一座电话亭的来电，将五起案件拼成了一个所有人都愿意相信的故事。玩家扮演调查员顾言，通过现场勘查、证物组合、人物审讯、时间线重建与最终报告，还原一场被“连环杀手”叙事隐藏的单一谋杀计划。

## 主要内容

- 6 个章节与 5 种结局
- 17 个地点节点与场景热点调查
- E001–E075 原始证物、独立鉴定记录与多来源推论三层证据体系
- 7 名核心人物与三轮口供
- 15 个核心谜题、证据组合和推理板
- 公交排班时间线、旧照片显影与 10 项案件报告
- 谜题与审讯采用证据门槛，不能跳过调查直接猜答案
- 旧地点新线索提示、可选紧急行动，以及仅由错误判断与无效尝试累积的调查压力
- 五案异常对比与四案完整排班时间线
- 第五案采用事实横向表自行识别模式断裂，并为错误归因提供反证复盘
- 最终审讯采用三段证据攻防与未裁切底片连续播放，报告标题和案件定性必须逻辑一致
- 第四章按技术矛盾、证据指向的旧案地点与照片恢复分为三个调查阶段
- 使用 `localStorage` 自动保存，无需登录或服务器
- 桌面和移动端自适应界面

## 本地运行

直接打开 `index.html`，或在目录中启动任意静态文件服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 技术

原生 HTML、CSS 和 JavaScript。无框架、无构建步骤、无第三方运行时依赖。

`smoke.cjs` 使用 Playwright 进行开发回归，覆盖不修改存档的六章自然流程、证物数据格式、证据门槛、地点重查、第五案反证反馈、最终底片演出、报告一致性、五种结局、黑暗结局可达性与移动端布局。

## 内容提示

游戏包含犯罪案件、死亡、火灾与事故相关文字描述，不包含写实血腥图像。
